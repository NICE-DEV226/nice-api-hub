How it works

01

Paste the link

In the app or on the command line. nah asks the API what the link resolves to — title, duration, every quality available.

02

Providers race

The API tries fast dedicated providers first, falls back to yt-dlp, caches the result. Dead content is reported honestly, upstream faults trigger failover.

03

File lands

Streamed in ranged chunks, merged with ffmpeg when needed, saved with a unique name — never overwriting what you have.

Scriptable

No terminal UI? Every action is also a one-line command, so nah drops into cron jobs, SSH sessions and CI.

Built for real use

Resumable playlists

Whole playlists download item by item with an on-disk checkpoint. Close the laptop, come back, resume where it stopped.

Self-updating

nah update fetches the release archive, checks it against SHA256SUMS and refuses on mismatch.

Secrets in the keychain

API keys live in your OS keychain — never in a dotfile. Falls back to a 0600 file where no keychain exists.

Honest about limits

The README lists what is not verified yet — macOS/Windows by hand, datacenter IPs on YouTube. No marketing fog.
